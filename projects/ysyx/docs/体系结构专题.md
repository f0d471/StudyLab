## 0. 结论先行

1. **YSYX 可以逐步搭成可检验的体系结构实验链**：ISA 功能参考(NEMU)、RTL 实现(NPC)、差分测试、AM/Navy 软件栈、ysyxSoC 与构建追踪。当前新 Main 只完成初始环境与示例验证，NPC 仍是骨架；完整实验链是后续目标。每个研究问题仍需单独确定功能或性能判据，不能因为使用这套框架就视为已验证。
2. **平台覆盖的主干是六个领域**:处理器微架构与 ISA、存储层次、操作系统与运行时、编译与工具链、总线与 SoC、验证方法学。讲义已经写进主线的是前五个加上验证的入门;真正的纵深(缓存一致性、虚存进阶、分支预测、乱序、向量、加速器)在讲义里是点到为止或列为 A 阶段待续,要靠自己做实验补。
3. **课程主线负责建立基础，扩展实验负责研究机制**：缓存、预测器、向量与加速器等方向见第 2 节的 14 个候选实验。开工前先检查处理器、参考模型、软件负载与测量设施；difftest 只覆盖其声明的功能比较范围，性能结论另用测量和模型校准。
4. **文献部分按领域分层组织**(第 3 节),列出"复现什么、挂在哪、入口"候选。凡标注 DOI 的,多数需要校园网或图书馆权限;arXiv 与课程页链接可直接打开。

### 1.4 三种"平台之上"的扩展点

以下扩展点在基础实验链接通后使用；不要求所有平台项目都连接自研 CPU。

1. **更换 RTL 实现**：在相同 ISA 与软件接口条件下保留 NEMU、AM 和差分装置，对比微架构；先明确异常、MMIO 和提交边界。
2. **增加性能模型**：保留 NEMU 的功能参考，按问题另接 gem5 或自写模型，研究缓存、预测与并行性。性能模型需要独立校准，不能视为可直接替换 ISA 差分接口的组件。
3. **换掉软件栈,保留处理器**:在自研处理器上跑更重的软件(xv6、Linux、RTOS、AI 推理)。验证的是 ISA 与 OS 接口的完备性,也是最好的 bug 探测器。

### 2.1 微架构与 ISA

### 2.5 创新方向:YSYX 思想能迁移到哪里

"YSYX 思想"里真正有迁移价值的是四条,每条都能独立成为课题方向:

1. **可执行规范 + 差分测试**(NEMU 之于 NPC)。迁移:自研加速器之于其黄金模型;自研 GPU 之于软件光栅器;AI 加速器之于浮点参考实现。要点是参考模型必须与被验对象在抽象层次上不同,否则是自证。
2. **抽象层收口**(AM 之于硬件差异)。迁移:一套 NPU 驱动接口下面挂不同数据流;一套图形 API 下面挂不同光栅器。抽象层是控制复杂度的工具,也是"换实现不改上层"的前提。
3. **渐进式目标**(从 4 条指令到 Linux)。迁移:任何大工程都该有一串"每步都能跑起来"的里程碑,每一步都可验收。
4. **过程即证据**(tracer-ysyx 把构建与运行自动记录成可追溯历史)。迁移:自研项目的回归与实验记录自动化,尤其在"用 AI 辅助开发"时代,过程证据比结果更能证明能力。

值得关注的空白位置(总纲 4.6 已有 GPU 线的判断,这里补充体系结构侧):**开源世界里"教学级 CPU"很拥挤(ysyx、Nand2Tetris、From Nand to Tetris、Tiny Tapeout 教学核),但"有完整软件栈和验证方法学的加速器"很空**。VTA 多年未更新,VeriGPU 停更,tiny-gpu 是教学级;真正能对拍、能上板、能跑真实框架的开放加速器极少。这个位置比再做一遍 CPU 更值得投入。

## 4. 在 StudyLab 中使用本专题

1. **先核对 YSYX 的实际基础**。新 Main 与 raw 旧工程分别登记，沿主线建立 ISA、异常、缓存与流水线设施；按知识诊断补 CS61C 或系统编程的缺口，不重做多套相同入门课。
2. **量化研究先于复杂微架构**。先定义指令、周期、工作负载与计数方式，做缓存参数或分支行为的小实验，再进入超标量、重命名、ROB 与乱序研究。
3. **随机测试与形式方法按实验条件加入**。未接通 NPC 时先研究生成器、参考模型与小部件；系统级 difftest 接通后再评价缺陷发现能力。
4. **虚存与 OS 分两步联动**。MIT 6.1810 的 xv6 课程在平台独立项目中完成；自研处理器满足 ISA、特权级、MMU 与启动条件后，再开展移植实验。QEMU 上通过不等于 NPC 上通过。
5. **GPU 与 AI 的工程交付仍由总纲负责**。本专题可研究其机制与模型；需要作为 G 线、IC-11 或推理引擎的设计依据时，引用固定版本、配置和证据，不复制另一份工程进度。
6. **按研究问题选读文献**。一次选一个问题和少量直接相关材料；原文献清单是候选索引，本次未逐条重新核验题录、DOI 与当前工具状态，正式实验引用前再核对。

本专题与其他课程共用 StudyLab 的活动名额和时间预算，YSYX 不另占一条永久并行主线。平台实施阶段以 [平台使用说明](../../../docs/通用学习平台.md)为准，现行运行方式仍以项目 AGENTS.md 和开发环境文档为准。
