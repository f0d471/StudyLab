# topics：YSYX 学习记录

讲义主线驱动的学习记录区。定位一句话：**先按部就班把 YSYX 主线走完，再在这个平台上做自己的拓展**。主线内容以官方讲义（2607 版，见[离线镜像](../site/index.html)）为准，这里不复制讲义正文，只沉淀我们自己的理解、实验与工程改造。

## 两棵树

| 目录 | 回答的问题 | 读者 |
| --- | --- | --- |
| [Knowledge/](Knowledge/) | 这门课的知识本身：主线教程、前置基础、实验记录 | 正在学这门课的人，按讲义阶段推进 |
| [Engineering/](Engineering/) | 我们对项目做了什么改造：路线、缺陷、开发过程 | 要接手 ysyx-workbench 改造的人，按开发时间线推进 |

同一件事在两边都出现是正常的，落点不同：Knowledge 讲"这个知识点怎么学会"，Engineering 讲"这段代码为什么长这样"。

## 与其他位置的关系

- 实际课程进度只维护在[项目 README](../../README.md) 的当前进度节；本目录不另建进度表。
- 主工程 ysyx-workbench 是独立 Git 仓，只放代码与其自身 docs；学习记录一律在本目录，不进工程仓。
- raw/ 两份旧工程仅供历史查阅，其验收不计入本工程；其中沉淀的写作规范与缺陷档案规范已由本目录继承（见 Engineering/Bugs/README）。
- 资料来源、离线镜像与维护规则见[资料目录 README](../README.md)。
