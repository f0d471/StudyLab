# tutorials：主线教程

按讲义 2607 版阶段组织，一个阶段一个目录：

```text
F/  数字逻辑基础（F1~F6）
E/  HDL、C、Linux、仿真验证、minirv、运行时、总线与 SoC、后端（E1~E8）
D/  从 C 到二进制、调试器、ISA、机器级表示、AM、RTL 实现、工具、NPC（D1~D8，即 PA 主线）
C/  ELF 与链接、设备与 IO、调试技巧、总线、SoC 系统（C1~C5，PA3~PA4 段）
B/  异常与简易 OS、时序分析、简易缓存、流水线（B1~B4）
A/  乘除、系统调用、虚存、特权级与 xv6、Linux、缓存进阶、分支预测（A 阶段）
```

一部分一篇，命名 `NN-<部分名>.md`（如 `D/02-调试器.md`）。篇内固定结构：

```text
篇首    出处块：讲义版本与章节链接、本篇解决的问题
前置基础 列出看懂本篇要先有的底子——必读的 fundamentals 篇目与前序教程各配一句
        "为什么需要"，可后置的标"用到再读"
正文    概念 → 原理（真实机制，配图） → 手把手操作 → 实验 + 判据 → 常见坑
篇末    讲义必答题逐题作答；自检问题每题都能用命令或实验验证，不凭印象答
```

推进状态勾在 `Engineering/Todo/学习与项目路线.md`，本目录不放状态表。
