# tutorials：主线教程

按讲义 2607 版阶段组织，一个阶段一个目录：

```text
F/  数字逻辑基础（F1~F6）
E/  HDL、C、Linux、仿真验证、minirv、运行时、总线与 SoC、后端（E1~E8）
D/  从 C 到二进制、调试器、ISA、机器级表示、AM、RTL 实现、工具、NPC（D1~D8，即 PA 主线）
C/  ELF 与链接、设备与 IO、调试技巧、总线、SoC 系统（C1~C5，PA3~PA4 段）
B/  异常与简易 OS、时序分析、简易缓存、流水线（B1~B4）
A/  乘除、系统调用、虚存、特权级与 xv6、Linux、缓存进阶、分支预测（A 阶段）
```

讲义的一个部分对应一个子目录，命名 `NN-<部分名>/`，例如 `E/04-仿真与验证/`。目录里一章一个文件，命名 `NN-<章名>.md`，章号从 01 起。每章的实验目录在 labs/ 下同名，例如 `labs/E/04-仿真与验证/01-Verilator把电路变成程序/`。

章的固定结构与写法见[知识库 README](../README.md)第 4、5 节，生产流程见[生产指南](../生产指南.md)。状态只有定稿与素材稿两种，含义见知识库 README 第 9 节；正在走独立审稿的新章标"实验双绿，独立审稿待补"（实验判据已全绿，审稿通过后改标定稿）。学员的学习检验是否通过不记在这里，记在[项目 README](../../../../README.md) 的当前进度节。
