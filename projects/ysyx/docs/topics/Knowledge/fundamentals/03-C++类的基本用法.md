## 这篇要回答的问题

1. class 和 C 的 struct 差在哪？成员和方法是什么？
2. `.` 和 `->` 各什么时候用？new/delete 和栈对象怎么选？
3. Verilator 生成的 Vtop 对象上，哪些是成员、哪些是方法？

## 1 class 是加了函数的 struct

C 里 struct 是字段打包：

```c
struct Counter { int v; };        // 只有数据
struct Counter c; c.v = 3;        // . 访问成员
```

C++ 的 class/struct 在此之上允许**成员函数**（方法）：数据和行为绑在一个类型里。class 与 struct 唯一的默认差异：class 成员默认私有（private，外部不可访问），struct 默认公开（public）。Verilator 生成的端口全是公开成员，所以你能 `top->a = 1` 直接赋值。

```cpp
struct Counter {
  int v;              // 成员变量（数据）
  void inc() { v++; } // 成员函数（方法）：作用在对象自己的数据上
};
```

## 2 对象、`.` 与 `->`

对象 = 该类型的实例。访问成员用 `.`（对象本身）或 `->`（指向对象的指针）：

```cpp
Counter c;   c.v = 3;   c.inc();     // 对象：用 .
Counter* p = &c; p->v = 4; p->inc(); // 指针：用 ->（等价 (*p).v）
```

规则一句话：指针用箭头，对象用点。testbench 里 `Vtop* top = new Vtop;` 拿到的是指针，所以全程 `top->`。

## 3 生命周期：栈对象与 new/delete

```cpp
Counter c;            // 栈对象：作用域结束自动销毁
Counter* p = new Counter;  // 堆对象：手动 new 出来
// ... 用 p
delete p;             // 用完手动释放，不删就是泄漏
```

为什么 Verilator 用 new：模型对象内部结构大（整个电路的状态），且生命周期覆盖整个 main，堆上放、用完 delete 是惯用形态。`top->final()` 是模型提供的收尾方法（flush 内部缓冲，波形相关），在 delete 之前调一次。

## 4 构造：new 时发生什么

`new Vtop` 做两件事：分配内存 + 调用构造函数初始化成员。有的类型构造需要参数（如带参的类），Vtop 的构造无参，直接 new 即可。"构造函数是初始化钩子"这个概念到批 8 前都用不上更多，记住"new 出来即已初始化"够用。
