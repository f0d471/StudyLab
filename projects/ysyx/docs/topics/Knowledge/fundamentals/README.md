# fundamentals：前置基础

收三类内容，均纳入学习线。

1. **基础原理**：课程要用或需要深入理解的机制，例如模型求值、事件调度和状态更新。
2. **系统专题**：围绕学科问题建立模型、方法、对照实验、反例及边界，例如仿真器实现与验证方法。课题由阶段 spec 登记，与 tutorials 交叉带学。
3. **速查资料**：选项、类型等表格随实验查用，相关作用在课堂解释。

学习后回补现有篇目的缺口，新增篇目先明确问题、依赖和实验；流程见[知识库 README](../README.md)与[总路线](../../Engineering/Todo/学习与项目路线.md)。

目录按主题分堆：`01-仿真器`、`02-Verilator`、`03-描述电路`、`04-验证方法学`。篇号在主题目录之间全局递增（新篇取当前最大号之后的下一个号，编号永不回填），所以跨主题引用写"fundamentals/NN"不会歧义。维护规则如下。

1. 用到才开篇。教程依赖或阶段 spec 中有明确学习问题、前置与实验计划时可开篇；专题与引用方互链。
2. 篇放主题目录下，文件名 `NN-<篇名>.md`，一篇只讲一个主题；实验目录 `labs/fundamentals/<NN-主题>/<NN-篇名>/` 与之一一对应。
3. 各篇不重复。同一知识写在先出现的那一篇，后面的链接过去。
4. 罗列型内容做成表格，便于查。
5. 写法、依据与状态规则见[知识库 README](../README.md)，生产流程见[生产指南](../生产指南.md)。C++、Makefile、GCC 的基础先在实验中就地补齐；需要独立专题时先在路线登记。
