# fundamentals：前置基础知识

两类内容：

1. **前置知识**：主线教程要用但讲义默认你已经会的底子（C 语言细节、GNU 工具用法、数字逻辑结论等）。
2. **罗列型手册**：主线不方便展开、展开会淹没叙事的内容——每条指令的具体编码与语义、每个 CSR 的位段、每个函数的语法与标准行为、每个工具的选项表。

维护规则：

- **用到才加**，不预先写全；没被任何教程引用的篇不开。
- 篇名 `NN-<主题>.md`，一篇只讲一个主题；新术语给中文名、全称、来历（例：`sdb` = simple debugger，NEMU 的简化调试器）。
- 讲"标准规定的行为"时注明出处条款（C 标准引用公开草案 N1256/N1570 即可，正式文本收费；RISC-V 语义以 docs/sources/riscv/ 手册章节为准）。
- 各篇不重复：同一知识谁先出现写在谁那里，后面的链接过去。
- 罗列型内容优先做成表格（指令字段表、位段表、选项表），便于查而不是读。

当前无篇目；第一篇等教程正文第一次需要跳转时建立。
