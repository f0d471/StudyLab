# fundamentals：前置基础

收两类内容。

1. **前置知识**：主线教程要用、讲义默认读者已经会的底子，例如 Verilator 生成的模型怎样求值。
2. **罗列型手册**：放进主线会淹没叙事的成堆内容，例如工具的选项表、指令编码表、CSR 位段表。

维护规则如下。

1. 用到才开篇。没有被任何教程引用的篇不写。
2. 篇名 `NN-<主题>.md`，一篇只讲一个主题；实验目录 `labs/fundamentals/NN-<主题>/` 与之同名。
3. 各篇不重复。同一知识写在先出现的那一篇，后面的链接过去。
4. 罗列型内容做成表格，便于查。
5. 写法、依据与状态规则见[知识库 README](../README.md)，生产流程见[生产指南](../生产指南.md)。C++、Makefile、GCC 的通用基础不在本库开篇，教程用到时就地讲清需要的那一点。
