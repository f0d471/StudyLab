# labs：课程实验记录

讲义各阶段实验的落地记录：每个实验写清输入、命令、预期、实际结果与限制。判据是实验的一部分，没有判据的实验等于没做。

组织方式：按讲义阶段建目录（`D/`、`E/`……），实验代码与脚本放在主工程对应位置（ysyx-workbench 内），本目录只放**记录**：跑法、判据、实测输出摘录、日期与环境。

- 实验判据要能"注错见红"：故意改坏一处，判据必须失败。
- 原始日志在 StudyLab/logs/ysyx/ 或项目 logs/，记录里引用位置，不整段粘贴。
- 实验失败与否定结论照记，不删除；它们是回归网的一部分。
- 一个实验从"讲义要求"到"本地判据"的转化过程写在记录开头——讲义判据含糊的地方（如"观察输出"）要落成机器可查的具体条件。
