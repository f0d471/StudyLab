# TechReports：工作点开发过程

一层一个系列目录，系列内一章一个工作点，写完定稿。读者是要接手改造 ysyx-workbench 的人：讲的是"这段代码为什么长这样、当时怎么走的、被否决的方案是什么"，不是教程。

- 工作点完成后从 `Todo/学习与项目路线.md` 勾状态并在此成章；过程中修掉的 Bugs 一并归入对应章。
- 章内要有：目标与判据（开工前写在 Todo 里的那两行）、关键改动、实测数字（本机实跑，不抄讲义）、被否决的方案、遗留。
- 引用路径用仓库相对路径；原始日志、波形放 logs/ 或对应忽略目录，正文只引用位置与结论。

当前没有已归档系列。第一个工作点（PA1 调试器）完成时建立 `01-pa-nemu/` 之类的系列目录。
