# YSYX 二周目学习与项目路线

建立：2026-10-19。本文是 Todo 唯一一份总路线，学习与工程改造的状态都在这里勾。

## 定位与工作方式

- 二周目：讲义驱动，先按部就班走完 YSYX 主线（2607 版讲义），主线完成后才在平台上做自己的拓展。
- 主工程是 `projects/ysyx/ysyx-workbench/`（官方框架新工程）；`raw/` 两份旧工程只当参考实现与地雷图，其验收不计入本路线。
- 工作节奏：对话式教学，一次 2~3 个概念，批末自测，全对再进下一批。
- 记录分工：学到的知识进 `Knowledge/`（教程、基础、实验），工程改造过程进 `Engineering/`（TechReports、Bugs），实际进度勾在[项目 README](../../../../README.md)。
