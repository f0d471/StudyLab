## 工具与运行方式

profiles/studylab.json 分离环境 ID 与 volumeId；注册项目使用自己的 cwd、环境、HOME、缓存和日志。共享资源池约束所有子项目。YSYX 原工具安装前缀只在项目沙箱内兼容，其他项目默认不可见；共享工具另以只读方式声明。

旧 WSL mount unit 已停用并归档，新 unit 根据状态生成。setup-linux.py 不再回写旧 fstab 条目。缺卷时拒绝运行，恢复挂载后正常；两次 Setup 不改变 fstab。未执行 Windows 或 WSL 冷启动，不能把停止后恢复等同于冷启动测试。

新目录最初在 case=dir 下创建失败。未采用 Windows ACL 扩展；保留 ACL 改用 case=off 后目录创建与课程环境运行通过。此模式的大小写语义限制见开发环境。复杂参数检查发现 systemd-run 默认环境展开，已以 --expand-environment=no 修复并通过两种 PowerShell 与 WSL 回查。
