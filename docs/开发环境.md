# 开发环境

更新：2026-10-16。StudyLab 使用原 12 GiB 固定 NTFS VHDX，Windows 入口为 E:\Workspace\StudyLab，WSL 管理挂载为 /mnt/wsl-sandbox/studylab。底层 ysyx.vhdx、卷 GUID 与 token 保留，显示名称与项目 ID 已分离。

## 入口与配置

通用工具在 Workspace/Tools/wsl-sandbox；profiles/studylab.json 管理卷和共享资源，profiles/ysyx.json 是兼容重定向。platform/projects.json 登记项目目录，各项目 project.json 管理 cwd、环境、能力、时限与只读共享输入。

Windows PowerShell 5.1 与 PowerShell 7 均支持：

```powershell
& .\Tools\wsl-sandbox\sandbox.ps1 -Action List
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Doctor -Project cs61b
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Shell -Project ysyx -Gui
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Run -Project cs336 -Gpu -Command @('/usr/lib/wsl/lib/nvidia-smi')
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Stop -Project cs61b
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Stop -All
```

默认项目为 ysyx。WSL 使用 bash /mnt/e/Workspace/Tools/wsl-sandbox/run.sh --project <ID> shell，或 run 后跟 argv。参数通过数组和 Base64 JSON 传输，systemd-run 关闭环境展开，空格、引号、中文与字面美元符号保持原样。

## 共享限制与文件视图

| 对象 | 范围 |
| --- | --- |
| 内存 | 全平台累计 3 GiB，2.5 GiB 开始回收，零 swap |
| CPU | 全平台累计 200% CPU 时间，约相当于 2 核 |
| 进程与线程 | 全平台累计 256 |
| 会话 | 每次最多 30 分钟，含等待输入；项目只能设更短时限 |
| 临时盘 | 每次 256 MiB tmpfs，同时计入内存 |
| 普通文件 | 单文件最多 2 GiB；core dump 关闭 |
| 持久数据 | 整卷 12 GiB；少于 256 MiB 拒绝启动任务，安装前另估峰值 |

各项目子 slice 共用 studylab.slice 的上限，Stop -Project 不停止其他项目。平台只给当前项目 /workspace、独立 /home/sandbox 与 /cache 写权限；系统目录、共享工具和声明的 /inputs 为只读。宿主 HOME、其他项目与 Windows 互操作不开放。网络、GUI、GPU 都需在描述中声明，再显式启用。

YSYX 的 cache 保留在其项目内部，兼容原工具的相对布局；其他项目缓存默认在平台 cache/<ID>。Verilator 5.052 保留原安装目录，在 /toolchains/verilator-5052 只读共享。其他项目使用时在自己的环境设置 VERILATOR_ROOT=/toolchains/verilator-5052/share/verilator，并将相应 bin 加入 PATH；不复制工具。

## NTFS 与依赖

当前新挂载使用 metadata、case=off，不修改 Windows ACL。case=dir 曾使新目录的大小写标记操作被 NTFS 权限拒绝；改用 case=off 后目录创建和编译运行通过。此设置意味着本挂载按不区分大小写语义工作；需要仅大小写不同文件并存的项目须另行选择合适文件系统或配置，不能静默覆盖。依据见 [微软大小写说明](https://learn.microsoft.com/en-us/windows/wsl/case-sensitivity)。

WSL 系统包共享，项目自己的 Python venv、Java 缓存和锁文件分开；源码在 Windows 编辑，Linux 可执行位与符号链接保留。现有基础工具来自已记录的 WSL 安装；本轮未安装整套新课程依赖。

GPU 通过显式 -Gpu 开放 /dev/dxg 与只读 WSL 驱动库。设备查询已识别 RTX 4060 Laptop；CPU cgroup 不限制 GPU 显存。CUDA 工具链、PyTorch、训练、多卡与大模型未在本轮验证，cs336 尚未安装课程作业。GUI 共享显示服务，不作为恶意代码的完整安全边界。

## 挂载与恢复

WSL 挂载由配置生成的 systemd mount unit 随 local-fs.target 恢复；Setup 和 Mount 不再向 fstab 写卷条目。Windows 虚拟磁盘未连接时执行 -Action Mount，按需要由系统管理员挂载原 VHDX。缺卷、错误身份或限额不符时拒绝运行，不退回普通目录。

原卷状态仍在 Tools/wsl-sandbox/state/ysyx.json，与卷内 .wsl-sandbox-volume.json 保持一致。重装与备份应覆盖平台仓、各项目仓、未提交材料、原始证据、HOME 与卷外 profile/state；只备份 Main 无法恢复整个平台。迁移原状态与恢复映射见 [环境改造记录](环境改造记录.md)。
