# 通用学习平台

StudyLab 是课程与研究实验的共同载体。这里维护可运行的项目、必要资料、实验记录和环境；每个项目说明自己研究什么、用什么判据检查、还有哪些未完成。

## 内容范围

- 基础课程：数据结构与算法、组成原理、操作系统、编译原理，以及按需要补齐的离散数学、概率和线性代数。
- 体系结构研究：性能量化、缓存与预测、超标量与乱序、虚存、软硬件接口、验证与模型校准。
- ML 系统学习：模型计算、分词、数值与性能、训练和推理机制的小规模实验。
- 其他研究：有明确问题、来源、前置条件和可复查判据时，以新项目接入，不限制在 YSYX 内扩展。

操作系统与编译原理尚未作为已安装项目登记；需要时新增 xv6、cs143 等项目。复杂主题允许先做教学原型、模型和手工推导，不要求产品化；研究结论必须写明条件与限制。

## 日常使用

在 Workspace 根目录执行：

```powershell
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Doctor -Project ysyx
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Shell -Project ysyx
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Shell -Project cs61b
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Run -Project cs61b -Command @('python3','-B','tools/smoke.py')
```

在 WSL 终端执行同一入口：

```bash
bash /mnt/e/Workspace/Tools/wsl-sandbox/run.sh --project ysyx shell
bash /mnt/e/Workspace/Tools/wsl-sandbox/run.sh --project cs61b run python3 -B tools/smoke.py
```

进入后项目映射到 /workspace，YSYX 默认位于 /workspace/Main。普通课程不会继承 NEMU_HOME 等变量。exit 结束会话；Ctrl+C 中止前台任务。会话含等待输入在内最多 30 分钟。

GUI、联网和 GPU 都需要项目描述声明，再用 -Gui、-Network、-Gpu 显式开启。cs336 的 GPU 查询只验证设备通路，完整训练需要另外安装并验证依赖。详细限制见 [开发环境](开发环境.md)。

## 接入新项目

```powershell
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Add -Project xv6 -Kind course
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Shell -Project xv6
```

Add 只创建项目目录、project.json、学习约定占位并登记，不下载源码或安装依赖。已有非空目录需要显式 -Existing；不覆盖已有描述文件。不再学习时先保存成果与引用，再从注册表移除；清理代码与数据是单独操作。

在项目 README 填写问题、前置条件、来源版本、首轮范围、完成判据和未完成项。按课程自身结构组织源码，必要时增加 notes/、tools/、results/；虚拟环境、大数据、模型、波形和构建产物忽略。共享代码或输入通过 project.json 的 sharedInputs 声明，只读映射到 /inputs/<名称>。

## 实验与证据

课程单元以解释、题目和实验为完成依据；研究记录包括问题、假设、基线、变量、命令、原始数据和限制。功能正确与性能收益分别验证。失败与否定结论有保留价值，不能因为没有改进就删除。

运行记录在 logs/<项目 ID>/，包含项目、argv、代码版本、dirty 状态、资源池、能力开关与退出码。交互只保存会话元数据，普通终端输入输出不自动录制。YSYX 迁移前的证据保留在其项目 logs/，通过 [环境改造记录](环境改造记录.md)查旧路径。

平台共享资源与工具版本，各项目独立 HOME 和依赖。资料长期收录沿用 Reference 的管理方式，项目只保存真正使用的材料，不复制整个参考库。
